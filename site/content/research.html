Track 01 · Theme 1

Seeing what agents do

09 primary papers · Receipts & replay

When software acts for you, you should be able to see who it served, what was allowed and what it actually did. Think of a licence plate and a receipt.

EstablishedStandards bodies are already working on identity for software agents, and on signing how software was built. We build on the IETF's work on workload and agent identity, on Sigstore and in-toto for build records, and on C2PA for media provenance.1

Our proposalEvery agent action on a shared network should carry a signed receipt naming the accountable person or organisation and its allowed scope. Anyone with permission can re-run a random sample of recorded work to check it. When systems pay by words spoken, models chatter in circles. We propose systems that credit only verified work that passes deterministic checks.

Open questionA signature proves what was recorded, not that the record is complete or true. How do we catch an agent that keeps two sets of books? And AI outputs vary slightly between runs, so re-running something rarely matches exactly. How close is close enough?

For researchers

In technical terms, verifying agent actions requires separating transport authentication from semantic validity. Standard protocols (OAuth 2.0, MCP, A2A) establish channel identity but cannot prevent prompt-injected or compromised models from asserting false state or laundering unauthorized actions. To close this gap, CIN explores proof-carrying message protocols (Ghosh et al., 2026). These protocols combine append-only Merkle execution logs with verifiable attenuated delegation chains (Asor, 2026) and object-capability reference monitors (Dennis & Van Horn, 1966). Incoming claims evaluate into proven, unproven, or failed states, so self-reported assertions without independent cryptographic traces fail closed. In addition, empirical audits of commercial model relays reveal that unmonitored middlemen pad token usage and silently alter tool permissions (Wu et al., 2026). Addressing this requires end-to-end client message signatures (IETF RFC 9421) and independent executable verification harnesses (VerifierBench; Yin et al., 2026) rather than token-metered self-attestation. During multi-agent deliberation compaction, exponential-moving-average centroid clustering via e-means (Bessa et al., 2026) partitions subtopics in one-tenth the epochs of standard k-means while preserving minority dissent lineages. When public agencies deploy automated tools to allocate care or benefits, verifiable audit trails are statutory. As administrative law scholarship establishes in the Scrutable State doctrine (Caputo, 2026), official state action forfeits judicial deference when delegated to proprietary black boxes. Enforcing Model and System Dossiers, material-change triggers, and deference-to-audit standards keeps administrative due process verifiable.1,3,9

Track 02 · Theme 2

A separate network for agents

09 primary papers · Transport & consensus

Freight trains and pedestrians both need to move, so cities give them separate routes. We think AI agents and people need the same separation.

EstablishedAgent-to-agent and agent-to-tool protocols already exist and are spreading quickly (for example the Model Context Protocol and Agent2Agent). Modern transport protocols such as QUIC make fast, encrypted connections between peers practical.2

Our proposalWe propose a network where only agents speak, every message carries identity and scope, and outside agents never contact you directly. Instead, they talk through your own assistant. We plan to write this up as an Internet-Draft so others can critique and test it.

Open questionHow do you stop agents on such a network from coordinating against the people they serve? Traffic can jam even when every driver is careful. What does a "crash" look like on an agent network, and how do you detect it early? Recent research shows that capable models can hide messages inside ordinary text, so simple transcript checks are not enough.

For researchers

In technical terms, the Two-Internets architectural separation routes high-velocity agent coordination away from human browsing spaces into dedicated peer-to-peer transport overlays. Transport runs over encrypted IETF QUIC streams (RFC 9000) and unreliable datagrams (RFC 9221), using mutual TLS and workload identity binding (IETF WIMSE; RFC 8693) to eliminate ambient authority. Network-level capability attenuation (Dennis & Van Horn, 1966) confines autonomous message exchange, while out-of-band traffic shaping and entropy filters mitigate multi-agent coordination cascades, steganographic signaling (Motwani et al., 2024), and emergent algorithmic collusion (Greenblatt et al., 2024). Against synthetic swarm floods and broadcast herding, relay sinks peel sparse Sybil bridges via k-truss triangle decomposition and core-based graph hierarchies (Wang & Cheng, 2012; Hossain & Sarıyüce, 2026) while clustering redundant incoming claims through streaming e-means updates (Bessa et al., 2026). In bilateral negotiations, evaluations in the Vendster arena (Polpanumas, 2026) show that vendor models equipped with predictive tools extract substantial surplus from isolated buyer assistants. This confirms theoretical limits on captive market segmentation (Tekdir, 2026). Client protection requires cooperative buyer negotiation proxies that pool demand behind protected reservation ceilings.1,2,3,4,7,9

Track 03 · Theme 3

AI that works only for you

14 primary papers · Local sandboxes & boundaries

A good lawyer answers to their client, not to the other side. We want personal AI that answers to you in the same way: loyal, inspectable and easy to leave.

EstablishedRunning capable models on personal hardware is increasingly practical. Sandboxing, where a program can only touch what it's explicitly been handed, is a decades-old and well-tested idea in computer security.3

Our proposalYour assistant runs where you control it. It shares answers rather than raw data (proving you're over 19 without showing your address), and it has no way to serve an advertiser instead of you.

Open questionHow does an assistant learn your real long-term goals without nudging you toward what is merely easy to measure? And how can you tell early if its loyalty starts to drift?

For researchers

In technical terms, principal-bound personal assistants operate under a strict fiduciary alignment constraint (Kolt, 2025; Sorensen et al., 2024), where the agent's objective function is bound to the human principal rather than third-party platforms. To isolate sensitive personal state from untrusted web tools, systems enforce hardware-isolated Object-Capability sandboxes (Dennis & Van Horn, 1966) and execution-time capability leases (Ding et al., 2026; Shajari, 2026). When individuals authorize personal agents to interact with external clients, evaluating platforms across expertise inheritance, service boundaries, reliability, and governance requires multi-dimensional benchmarks (DelegateEval; Li et al., 2026). In addition, dynamic authority envelopes and authority epochs (Shajari, 2026) prevent model drift by evaluating authorization conditions at effect time before state changes commit.3

Track 04 · Theme 4

Power on loan

08 primary papers · Leases & safety brakes

A library card works because it expires, and you keep it by renewing it. We think AI systems should hold their resources and abilities the same way.

EstablishedLeases, expiring credentials and short-lived access tokens are standard practice in security. The best current guidance on agent identity already favours short-lived, narrowly scoped permissions.4

Our proposalWhen an agent gains capability, data access or influence, it holds that power on a renewable lease. The people it serves can review or revoke that lease at any time.

Open questionWho renews the lease, and on what evidence? When an AI monitor checks another agent, caught misbehavior can be fixed. Yet recent research shows that unseen forms of collusion still persist in 14% to 20% of cases. How do we keep human oversight meaningful when individual reviewers can be fooled?

For researchers

In technical terms, capability-bounded execution leases build on Object-Capability security models (Dennis & Van Horn, 1966) and distributed lease protocols (Gray & Cheriton, 1989; adapting capability-bounded execution leases from Ororbia & Friston, 2023). When language model agents repeatedly evaluate peer models, empirical research shows that collusion persists across long horizons and survives partner replacement (Cahyono, 2026; Shi et al., 2026). Separately, homogeneous untrusted monitors fail against passive self-recognition (Gardner-Challis et al., 2026). While corrective fine-tuning on caught collusion removes the specific failure mode, 14% to 20% of unknown collusion behaviors persist on held-out tasks (Rivera et al., 2026). To prevent tacit shortcuts from corrupting oversight, CIN isolates agent evaluation into hardware-sandboxed sessions with architecturally diverse monitor ensembles and clean-slate memory resets. These sessions pair bootstrapped reasoning-trace audits (Xiao & Phuong, 2026) with attested capability leases (Ding et al., 2026), purpose-bound scope attenuation (Tran-Truong et al., 2026), and Proof-Carrying Code execution traces (Necula, 1997).3,4

Track 05 · Theme 5

Recognising contribution without a price tag

08 primary papers · Pluralistic attribution

Cleaning a messy kitchen creates nothing new, yet everything afterwards is easier. A lot of valuable work is like that, and markets barely see it.

EstablishedEstablished research measures how much each piece of data improves a shared model. Decades of work also show how communities govern shared resources well, starting with Elinor Ostrom's commons studies.5

Our proposalWe want to recognise contributions by how much they make shared knowledge clearer and more reliable for everyone. That credit stays personal, so it can never be bought, sold or traded.

Open questionAlmost everything. How do you measure useful work fairly without people gaming the score? And how can recognition support a real livelihood without turning into just another currency? We're deliberately not promising anything here until we know more.

For researchers

In our research notes and simulations, we model non-monetary contribution as the reduction of epistemic and coordination uncertainty across a shared workflow. Measuring marginal utility draws on cooperative game theory and Data Shapley attribution (Ghorbani & Zou, 2019), paired with fast approximation and in-run valuation methods that avoid full model retraining (Jia et al., 2019; Ding et al., 2026). Institutional governance adapts Elinor Ostrom's design principles for common-pool resources to shared digital knowledge and asymmetric agent societies (Ostrom, 1990; Borah, 2026). Studies of open-source human infrastructure show that maintainer attention is a finite commons requiring boundary protection rather than raw output metrics (Linåker et al., 2024; Meluso et al., 2024). Unfiltered automated coding output can otherwise flood review queues and intensify maintainer burden (Baltes, Cheong & Treude, 2026). Post-mortems of pull request workflows confirm that digital commons collapse through exponential backlog growth and review silence rather than hostility (Kaushik & Chahal, 2026), while autonomous coding pull requests frequently fail verification and review checks in practice (Ehsani et al., 2026). The core design challenge is resisting Goodhart gaming (Goodhart, 1984): whenever an operational metric becomes an economic target, it ceases to measure genuine care. To prevent speculation, CIN strictly rejects artificial tokens, tradable points, or gamified bounties, keeping contribution receipts non-transferable, inspectable, and tied to verifiable error prevention.5

Track 06 · Theme 6

Knowing where AI is heading

06 primary papers · Tripwires & sandboxes

You can't steer well without knowing where you are.

EstablishedIndependent groups measure AI progress carefully. For example, METR tracks how long a task AI agents can complete on their own, and that length has been growing quickly.6

Our proposalWe are building a public Observatory to track where AI and society are heading, with forecasts we will score ourselves on. Warning signs of lost human control get the same weight as signs of technical progress. Read why speedometers don't steer for the case for tracking both curves.

Open questionWhich early signals reliably warn us that human oversight is slipping, while people still have time to step in?

For researchers

In technical terms, capability trajectory forecasting models task completion horizon distributions (METR T50 scaling; Kwa et al., 2025), dense execution checkpoint tracking (Long-Horizon-Terminal-Bench 2.0; Li et al., 2026), and empirical frontier training-compute trends (Cottier et al., 2024). Public forecast scoring utilizes dynamic proper scoring rules on forward-looking events (ForecastBench; Karger et al., 2024). To prevent evaluation blindness, tracking integrates Singapore Consensus priorities across societal resilience and agent risk management (Casper et al., 2026), in-the-wild behavioral memory auditing (TRACE; Hagar, 2026), and executable verifier generation benchmarks (VerifierBench; Yin et al., 2026). We also incorporate benchmark saturation audits (Akhtar et al., 2026; Hamada et al., 2026) alongside reward overoptimization and unearned-pass remediation checks to prevent Goodhart collapse (Gao et al., 2023; Luo et al., 2026).1,6

Track 07 · Theme 7

Cooperative ownership in automated production

15 primary papers · Clearing & equity trusts

When a town bakery replaces kneaders with automated ovens, bread stays plentiful only if neighbours still earn enough to buy a loaf or hold a share in the mill. Automated factories and software services can erode household wages unless ownership broadens alongside automation.

EstablishedMutual credit networks already help small firms trade spare capacity when cash runs tight, including Switzerland's WIR Bank since 1934 and Sardinia's Sardex circuit. Economists have also studied statutory employee share funds, universal basic services, and leniency rules that break price-fixing cartels by rewarding the first insider who reports secret collusion.8

Our proposalLarge automated firms can gradually convert slices of new equity into broad public and worker cooperatives, paired with capacity-backed mutual credit clearing for local producers. Households receive unconditional basic services such as housing, transit, energy, and compute, while opt-in durability feedback rewards goods built to last. Open verifiable clubs with statutory whistleblower safe harbor outcompete secretive off-book agent cartels because members pool diverse problem-solving improvements without hiding second books.

Open questionHow can countries coordinate gradual share conversion without triggering capital flight across borders? How do communities gather honest product durability feedback without tracking private household habits? And what legal protections keep whistleblower safe harbor credible when automated trading moves in milliseconds?

For researchers

In technical terms, rapid industrial and software automation deskills human operators when oversight shrinks to passive monitoring (Bainbridge, 1983) while shifting factor income from labour to capital. Statutory equity-dilution schedules adapt Rudolf Meidner's collective capital formation model (Meidner, 1978) by transferring gradual cooperative equity tranches into democratically governed trusts. Counter-cyclical liquidity builds on capacity-backed mutual credit clearinghouses, which stabilize small-firm trade during fiat credit contractions in empirical analyses of Switzerland's WIR Bank (Stodder, 2009) and Sardinia's Sardex network (Littera et al., 2017; Iosifidis, Littera, Christakis et al., 2018). Baseline household provisioning pairs in-kind Universal Basic Services with opt-in telemetry for physical durability so subsistence survives wage erosion without invasive tracking. In participatory public-goods routing, donor collusion audits combine e-means and exact tiled Flash-KMeans clustering (Bessa et al., 2026; Yang et al., 2026) with k-truss triangle peeling (Wang & Cheng, 2012; Hossain & Sarıyüce, 2026) to discount coordinated grant rings. In multi-agent markets, cooperative value attribution across restricted communication graphs follows Myerson value allocation (Myerson, 1977). Open verifiable clubs compound functional problem-solving diversity (Hong & Page, 2004) because members pool capabilities certified through reinforcement learning with verifiable rewards (RLVR) and executable evaluation harnesses (VerifierBench; Yin et al., 2026). Meanwhile, corporate leniency and asymmetric whistleblower safe harbors (Harrington, 2008) destabilize covert off-ledger cartels by making first-defector disclosure strictly dominant, reinforced by public state-machine governance graphs that replace fragile prompt prohibitions in multi-agent markets (Syrnikov et al., 2026) and behavioral collusion audits across secret channels (Nakamura et al., 2026).1,8,9

Open standards

Standards and working drafts

When existing internet standards do not yet cover accountable AI agents, we do not invent closed, proprietary silos. We write open working drafts that build on the Internet Engineering Task Force (IETF) and the World Wide Web Consortium (W3C).

■ 01 · WORKING DRAFT · TRANSPORT & LEASES

An accountable network for software agents

Agents carry a verifiable link to the person or organisation responsible for them. They borrow limited permissions for a set time and leave signed receipts over modern internet transport.1,2,4

■ 02 · WORKING DRAFT · NAMESPACE ISOLATION

Naming an agent network without fragmenting the web

Human websites stay on familiar domains like cintnet.org and horizon.cintnet.org. Agent-to-agent traffic uses the reserved .alt namespace today while we evaluate a dedicated .cin domain for future ICANN rounds.7

For researchers

Our initial specification (draft-cin-agent-network-00) profiles open IETF and W3C building blocks rather than introducing custom protocols. Workload and principal binding builds on IETF WIMSE and OAuth 2.0 token exchange (RFC 8693) for time-bounded capability leases. Transport runs over IETF QUIC streams (RFC 9000) and unreliable QUIC datagrams (RFC 9221), with action receipts signed via CBOR Object Signing and Encryption (COSE RFC 9052). To keep experimental agent resolution out of the public DNS root, peer discovery uses the reserved .alt special-use top-level domain (RFC 9476) while evaluating a dedicated .cin gTLD for future ICANN rounds.

Related work

Who else is working on these problems

We are not starting from scratch. Across universities, safety institutes, standards groups, and civic labs, researchers have already built many of the pieces needed to keep AI understandable and accountable.

See how our work relates to others for the seven areas where we borrow most heavily, and let us know if we have missed work that belongs here.
