Section 01 · Architecture & Alignment Bottlenecks

Ambient MCP tool authority, redacted speedup curves, and top-down rules

Anthropic built four important safety foundations: Constitutional AI, Responsible Scaling Policy ASL tiers, sparse feature interpretability, and the Model Context Protocol. As Claude shifts toward autonomous coding and desktop computer use, each pillar hits a structural boundary.

Standard MCP connectors verify identity once at login, leaving an execution trust gap afterward1. Shell and browser tools inherit full user permissions, so hidden instructions inside an untrusted repository or webpage can hijack live OAuth sessions. Meanwhile, sparse feature inspection remains a partial scientific lens that cannot replace external containment.

Competitive pressure also distorts transparency. Fear of helping rivals forced redaction of external reports measuring 2x internal researcher speedup, while employee Slack and monorepo links expose weights to twelve-hour theft.

Post-authorization MCP trust gap

MCP shell and computer-use servers run with ambient session authority, letting indirect prompt injections trigger unauthorized file or network actions1.

Redacted 2x R&D speedup reports

Publishing internal researcher acceleration numbers alone helps competitors, pushing safety-minded labs to redact empirical METR reports needed by external scientists.

Twelve-hour Slack and monorepo exposure

Human-in-the-loop developer laptops connected to corporate messaging leave training recipes and weights vulnerable to rapid state or agent exfiltration.

Top-down constitutional curation

Internal staff still curate most production constitutional rules because open web polls are easily flooded by synthetic bot accounts.
