# Contributing to `cintnet/cin-site`

1. Keep every factual or empirical claim grounded in a primary source (`arXiv`, `DOI`, `RFC`, or statute).
2. Run the repository's local test suite before opening a pull request.
3. Sign off commits (`git commit -s`) confirming you have the right to submit under the repository license.
4. Discuss open research or implementation questions on our website ([https://cintnet.org](https://cintnet.org)), in GitHub Discussions, or on Discord ([https://discord.gg/AANETMGc6Z](https://discord.gg/AANETMGc6Z)).
5. CIN accepts zero corporate equity and grants zero commercial vetoes.
